# Name brainstorm

The repo is called `lang` until we choose. Good language names are usually
**short (3–6 letters), easy to say, easy to search, and free as a file extension
and package name**. Before committing to one, check: GitHub, crates.io / npm /
PyPI, the domain, and that the file extension isn't already taken.

Mark favourites with ⭐ and strike out rejects with ~~tildes~~.

## Round 2: the Astra family (stars and space)

**About Astra itself:** a language called **ASTRA** already exists. It's an
agent-oriented language from University College Dublin, it's on Maven, and it
owns **astralanguage.com**, so "Astralang" would clash directly. There's also a
small Rust hobby interpreter called `astra` on GitHub, and Astro (the web
framework) is close in sound. Use Astra only as inspiration, not as the name.

## Round 6: around `langc`

The compiler is called `langc` for now. Most compilers follow the same habit: the language
name plus `c` (`rustc`, `javac`, `kotlinc`, `scalac`, `swiftc`, `tsc`, `gcc`). Quick web check, October 2026.

| Name | Check |
|------|-------|
| **Lang** | Works as a codename, but generic. Several hobby projects are already called `lang`, including a compiler ([ehrlich-b/lang](https://github.com/ehrlich-b/lang)). Hard to search for. |
| **Langc** | Not found as a language, but close to `langcc` (a compiler-compiler) and `lllc` (Langlanglang). |
| **Lanc** | Only the old PLANC (Norsk Data, discontinued) turns up. Compiler would be `lancc`, which is awkward. |
| **Lugha** | Swahili for "language". No programming language found. |
| **Clangor** | Free, but it sits right beside Clang, the LLVM compiler. Confusing. |
| **Lango** | A toy interpreter exists, and it is also the name of an ethnic group in Uganda. Avoid. |
| **Lex** | Collides with `lex`, the classic Unix lexer generator (and `flex`), so the command name is taken on most machines. |
| **Lexlang** | Nothing by that exact name, but close neighbours exist: [LxLang](https://crystaldoc.info/github/SleepingInsomniac/LxLang), LuxLang, Lexemn. It also reads as "lexer language". |
| **Langex** | A hobby script language called [langX](https://github.com/Aincvy/langX) exists, and so does a language-exchange app called LangX. |
| **Langue** | French for "language" or "tongue". Not searched yet. |
| **Lingua** | Latin for "tongue". Not searched yet; probably crowded. |

A habit worth deciding on now: the newer languages ship **one tool** named after the language
(`cargo`, `go`, `zig`, `deno`), with `build`, `run`, `test` and `fmt` inside, and keep the compiler
as an internal part. If we do that, the `c` suffix goes away and the name only needs to work as a
command. Until a name is chosen, `langc` is a single line in `compiler/Cargo.toml`, so renaming is cheap.

## Picking criteria
- [ ] Sounds good said out loud ("I wrote it in ___")
- [ ] Not an existing popular language/framework
- [ ] Searchable (`___ lang` returns nothing confusing)
- [ ] File extension is free and short
- [ ] Package name available on the registries you care about
- [ ] Fits the language's personality decided in [ROADMAP.md](ROADMAP.md) Phase 0

> Tip: decide the language's personality first (fast systems language? friendly
> scripting language?) — the right name gets much more obvious after that.
