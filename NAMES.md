# Name brainstorm

The repo is called `lang` until we choose. Good language names are usually
**short (3–6 letters), easy to say, easy to search, and free as a file extension
and package name**. Before committing to one, check: GitHub, crates.io / npm /
PyPI, the domain, and that the file extension isn't already taken.

Mark favourites with ⭐ and strike out rejects with ~~tildes~~.

## Short & punchy
| Name | Ext | Notes |
|------|-----|-------|
| **Kite** | `.kite` | Light, fast, flies high. (avoid `.kt` — that is Kotlin) |
| **Ember** | `.em` | Small spark that grows. |
| **Flint** | `.fl` | Strikes sparks; hard and simple. |
| **Quill** | `.ql` | Writing code like writing prose. |
| **Arc** | `.arc` | Clean, minimal; also an electrical spark. |
| **Vale** | `.vl` | Calm, elegant. (an existing research language uses this — check) |
| **Lumen** | `.lm` | Unit of light; "clarity". |
| **Tusk** | `.tk` | Strong, distinctive. |
| **Brisk** | `.bk` | Says "fast" on the tin. |
| **Nimbus** | `.nb` | Cloud-y; good if it targets the web/cloud. |

|------|-------|
| **Yet** | "Yet another language" — honest and memorable. |
| **Nova** | A new star (very popular word — searchability risk). |

## Picking criteria
- [ ] Sounds good said out loud ("I wrote it in ___")
- [ ] Not an existing popular language/framework
- [ ] Searchable (`___ lang` returns nothing confusing)
- [ ] File extension is free and short
- [ ] Package name available on the registries you care about
- [ ] Fits the language's personality decided in [ROADMAP.md](ROADMAP.md) Phase 0

> Tip: decide the language's personality first (fast systems language? friendly
> scripting language?) — the right name gets much more obvious after that.
