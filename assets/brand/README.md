# Pelago brand assets

The logo, icons, file icons and social images for Pelago. Design record and rules: [`docs/design/brand.md`](../../docs/design/brand.md).

`build/build.py` generates every file below, so the assets can be rebuilt after a change. The SVG files are the source; the PNG, ICO and ICNS files are exports of them. The wordmark in every logo SVG is outlined to paths, so no font is needed to display them.

## Rebuild

Needs Python 3.8+ and, for the PNG exports, Chrome, Chromium or Edge (found automatically; set `PELAGO_CHROME` to override). No other tools or packages.

```
python assets/brand/build/build.py              # everything (about 40 seconds)
python assets/brand/build/build.py --svg-only   # SVGs and the sprite only, no browser
```

PowerShell: `python assets\brand\build\build.py`. The SVGs rebuild byte for byte; PNGs can differ by a few bytes between browser versions.

The outlined letters come from `build/wordmark.json`. Change the wordmark, the `pel` file-icon label or the tagline by editing `build/outline_fonts.py` and running it (needs `pip install fonttools` and the Comfortaa and Outfit font files), then rebuild.

## Sprite

`icon/sprite.svg` holds the logos, the badge icons and the file icons as `<symbol>` elements, so a page loads one file:

```html
<svg width="32" height="32"><use href="sprite.svg#pelago-icon"/></svg>
```

Symbol ids are the file names without the extension: `pelago-mark`, `pelago-horizontal-dark`, `pelago-icon`, `pel-solid`, `pelago-toml-chart-dark`, and so on.

## Layout

| folder | contents |
|---|---|
| `logo/` | `pelago-mark`, `pelago-horizontal`, `pelago-stacked`, each as colour (`.svg`, for light backgrounds), `-dark` (lagoon, for dark backgrounds), `-black` and `-white` (one colour). PNGs on a transparent background: mark 1024, horizontal 2000 wide, stacked 1200 wide. |
| `icon/` | App icon `pelago-icon.svg` (teal badge) and `pelago-icon-dark.svg`; PNG ladder 16 to 1024; `sprite.svg`; `favicon.svg`, `favicon.ico` (16, 32, 48), `pelago.ico` (16 to 256), `pelago.icns` (16 to 1024, including the @2x sizes); `apple-touch-icon-180.png`, `android-chrome-192.png`, `android-chrome-512.png`, `maskable-512.png`, `mstile-150.png`; round avatars `avatar-512.png` and `avatar-dark-512.png`. |
| `editor/` | `vscode-icon-256.png` and `file-icons/`: the `.pel` source file icon in four styles (`outline`, `glyph`, `solid`, `band`) and the `pelago.toml` manifest icon in three (`chart`, `solid`, `anchor`), each with a `-dark` variant for dark themes, as SVG and 128px PNG. |
| `spec/` | Design spec sheets: mark construction on the 128 grid, app icon corner radius and safe areas, lockup clear space and minimum sizes. Generated by the build script, with Outfit embedded so they look the same everywhere. |
| `fonts/` | Outfit (variable font) and its SIL OFL licence. Embedded in the spec sheets; the logo outlines do not need it. Comfortaa is not bundled. |
| `previews/` | Static overview sheets (identity, icons, social and applications, file icons) made while choosing the design. They are not generated by the build script. |
| `social/` | `github-social-1280x640.png`, `og-1200x630.png`, `x-header-1500x500.png`, `linkedin-1584x396.png`, `readme-banner-1280x320.png`, plus a `-native` twin of each one that has a tagline (see below). |

## Quick rules

- Name: lowercase `pelago` in the logo, `Pelago` in prose.
- Colours: Pelago Teal `#0E7C86`, Lagoon `#5FD0C8`, Deep Sea `#0B2239`, Foam `#F4F6F8`. Use Deep Sea, not teal, for small text on white.
- Clear space: x = 28 units of the 128-unit mark (two strokes, 22 % of the mark's height) on every side. Minimum size: mark 24px (use the badge icon below that), horizontal lockup 140px wide. `spec/lockup-clear-space.png` draws both.
- Do not stretch, rotate, recolour, outline, add effects to, or put the logo on a low-contrast background.
- Fonts: wordmark in Comfortaa Bold, text in Outfit (both SIL Open Font License). Outfit is bundled in `fonts/` (OFL), Comfortaa is not; the outlines in `build/wordmark.json` are what the build uses. The wordmark is kerned (the `l` and `a` pair is pulled in by 30/1000 em), checked against the live font at 2000px.
- Editor extensions use the icons only. They never change the user's theme or workbench colours.

Two taglines, both kept, each on its own set of social images (set in Outfit, outlined): "A self-hosting systems language." on the plain files, and "Native code. No GC. No runtime." on the `-native` files. The README banner has no tagline.
